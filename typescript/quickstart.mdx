---

Use `@brello/sdk` in a server-side Node.js application. You need Node.js 18 or newer, a Brello project ingestion key, and credentials for your AI provider. Follow your provider SDK's Node.js requirements as well.

## Install the SDK

Install the Brello SDK in your application directory:

```bash
npm install @brello/sdk
```

To test from source, run `pnpm install` and `pnpm pack` in the SDK's `typescript` directory. From your application directory, run `npm install` with the tarball path printed by `pnpm pack`.

Keep your existing provider SDK dependency. For Google AI Studio or Vertex AI, install `@google/genai` if your application doesn't already use it.

## Set your Brello environment

```bash
export BRELLO_API_KEY="YOUR_BRELLO_PROJECT_KEY"
```

The SDK uses `https://api.brello.app/v1` by default. If you run Brello yourself, [set your self-hosted API URL](/typescript/configuration#connect-to-self-hosted-brello). Configure your provider credentials separately in your application.

## Wrap your client

Choose the client you already use. Create one Brello instance per application runtime so calls share a buffer.

<CodeGroup>
```ts OpenAI
import { Brello } from '@brello/sdk';
import OpenAI from 'openai';

const brello = new Brello();
export const openai = brello.wrap(new OpenAI());
```

```ts Anthropic
import { Brello } from '@brello/sdk';
import Anthropic from '@anthropic-ai/sdk';

const brello = new Brello();
export const anthropic = brello.wrap(new Anthropic());
```

```ts Google AI Studio
import { Brello } from '@brello/sdk';
import { GoogleGenAI } from '@google/genai';

const brello = new Brello();
const client = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });
export const gemini = brello.wrap(client, { provider: 'google_ai_studio' });
```

```ts Vertex AI
import { Brello } from '@brello/sdk';
import { GoogleGenAI } from '@google/genai';

const brello = new Brello();
const client = new GoogleGenAI({
  vertexai: true,
  project: process.env.GOOGLE_CLOUD_PROJECT,
  location: process.env.GOOGLE_CLOUD_LOCATION,
});
export const gemini = brello.wrap(client, { provider: 'google_vertex_ai' });
```

</CodeGroup>

Keep your existing provider calls. For setup and request examples, see the [OpenAI](/typescript/openai), [Anthropic](/typescript/anthropic), or [Google AI Studio and Vertex AI](/typescript/google) guide.

## Verify the connection

Complete a provider call or finish consuming its stream. In Brello, open your project's **Settings** and look for **Connected** under SDK activity. That status appears after the worker stores an event. For a short-lived test script, call `await brello.flush()` before it exits.

If the status stays pending, check your [project key](/guides/authentication) and set `BRELLO_DEBUG=1` to inspect event delivery. See [configuration and delivery](/typescript/configuration) for context, retries, and serverless examples.
