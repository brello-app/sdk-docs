| Property | Value |
| --- | --- |
| API version | `1.0.0-beta.2` |
| OpenAPI version | `3.0.0` |
| Base path | `/v1` |
| Authentication | Project key as HTTP Bearer |
| Request encoding | Uncompressed JSON |

Use your API deployment origin plus `/v1`. Local development defaults to `http://localhost:8000/v1`. The OpenAPI file uses the relative server URL `/v1`.

| Method | Path | Purpose |
| --- | --- | --- |
| POST | [`/v1/events`](/api-reference/events) | Submit completed provider attempts |
| GET | [`/v1/config`](/api-reference/config) | Verify a key and fetch settings |
| GET | `/v1/openapi.json` | Fetch the running server's public specification, without authentication |

Mintlify builds the endpoint reference from the [OpenAPI specification](/openapi.json).

<Note>
The playground is disabled while the specification uses a relative API URL. Use curl or a language guide with your deployment URL.
</Note>

## Shared response behavior

The public router sets `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, and a request identifier. Error envelopes include `requestId`. Authentication failures return `WWW-Authenticate: Bearer`. Retryable responses use `Retry-After` in seconds.

Read [authentication](/guides/authentication), [event semantics](/guides/events), and [errors and limits](/guides/errors) before building a client.
